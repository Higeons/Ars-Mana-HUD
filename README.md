# Ars Mana HUD

一个新生魔艺附属模组，为模组内的多种与魔力有关的物品提供增强显示。

本模组代码均由deepseek-v4-flash生成

---

### 功能

### 1. 魔力值显示（当前 / 最大）
在魔力条上叠加显示 `当前魔力 / 最大魔力`（如 `150 / 200`），文本实时跟随魔力条位置，可自定义 `MANABAR_X_OFFSET` / `MANABAR_Y_OFFSET` 调整偏移。

### 2. 魔力恢复速度
在魔力条右侧显示每秒恢复量（如 `+5.2/s`），单位小数保留 1 位。

### 3. 魔符 Tooltip 界面显示魔力消耗
在物品栏、法术书等GUI界面，以及 JEI 中查看魔符信息时，追加一行 `魔力消耗: Xmana`。

### 4. 法术书界面显示当前法术的魔力消耗
打开法术书时，会根据当前法术编写栏中使用的魔符实时计算总魔力消耗，并在魔力条上叠加显示 `Xmana`。

### 5. 手持施法工具显示施法的魔力消耗
- 手持法术书时，在法术名右侧显示当前所选法术的魔力消耗；
- 手持其他施法工具（如巫师之眼等）时，在魔力条上叠加显示。

### 6. 容器内容物精确数量显示（Jade）
需要安装 **Jade** 作为前置。视线看向新生魔艺容器时，在 Jade 提示框的模组名上方一行显示精确数量（精确至个位）：
- 魔源罐（含创造魔源罐）：`魔源量：X/Y`，X 为当前魔源量，Y 为最大魔源量
- 药水罐：`XX药水：X/Y mB`，XX 为药水名称，X 为当前药水量，Y 为最大药水量（mB 为流体单位）
- 魔源通道（农艺/炼金/菌丝/生死/火山）：`缓存量：X/Y`，显示其内部魔源缓存量

> 探索结构与开启星宝石兽的礼物获得的施法者卷册有魔力消耗减半的效果，显示的魔力消耗为减半后的真实魔力消耗

> HUD 文本在隐藏 GUI 或离开游戏时不会渲染；魔力上限与魔力恢复速度变化时才刷新文本。
